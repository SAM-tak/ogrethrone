# Test sounds

These three mono fixtures contain the same generated 0.125-second signal:
48 kHz, 440 Hz plus 0.3 times 1370 Hz, amplitude 0.08, with 10 ms linear fades.
They were created for this project, contain no third-party recordings, and may
be used and redistributed without restriction (CC0-1.0).

WAV is PCM16, Ogg is Vorbis, and MP3 is MPEG Layer III. Encoding used Python
SoundFile/libsndfile; these tools are not required to build or run the tests.
