# Editor font

`NotoSansJP-Regular.otf` is the unmodified Japanese subset of Noto Sans CJK,
version 2.004, from the upstream `Sans2.004` tag:

Copyright © 2014-2021 Adobe (http://www.adobe.com/).

- [Font](https://github.com/notofonts/noto-cjk/blob/Sans2.004/Sans/SubsetOTF/JP/NotoSansJP-Regular.otf)
- [License](https://github.com/notofonts/noto-cjk/blob/Sans2.004/LICENSE), included as `OFL.txt` (SIL Open Font License 1.1).
- SHA-256: `dff723ba59d57d136764a04b9b2d03205544f7cd785a711442d6d2d085ac5073`.

The editor uses this font for Latin and Japanese text, including project names,
paths and input fields. Its atlas includes all BMP glyphs available in the font.
